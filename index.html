模型评分榜 · 先用哪个模型

分数打给具体模型，不打给平台：同一个平台里旗舰模型和凑数小模型分开计。智力 40% + 额度 30% + 实用性 30%，满分 100；生图 / 生视频模型的「智力」按生成质量计。

分是怎么打的（两层）

第一层 · 卡片右上角总分（整个羊毛）：只由两项算出 —— 易薅程度占 45%（注册即用 5 分、一次实名/领取 4 分、每日手动领/签到 3 分、多步迁移/邀请/争议未核实 2 分）＋ 实用性占 55%（取该活动最值得用那个模型的实用分），公式为 易薅×20×45% ＋ 实用×20×55%，满分 100。这个总分不含智力、不含额度，只回答「好不好薅、薅到手好不好用」。第二层 · 具体模型分（点开明细看）：每张卡点开「免费模型明细」，能看到每一个免费模型自己的三维分和总分，评分榜也只排具体模型。智力看模型档位（旗舰级 5 分、主流强模型 4 分、够用小模型 2–3 分）；额度看该模型实际能分到多少量与重置方式（每日大额重置 5 分、每日小额或全池共享打折 2–3 分、一次性大额按总量折算）；实用性看接入难度、限流松紧、会不会自动转付费、能否接进 Magpie、商用与水印限制。需要绑卡 / 验证支付方式才能用的，整条直接不纳入；争议项（如 Hy3）实用性直接扣分。

这套监控怎么跑

国内线 + 海外线双轨，2026-11-03 扩容后的方法，检查时间点不变。

01

双线分流

学 Tokenation 并扩容：国内线追一次性发放，海外线专盯常驻免费档的政策变化（降额、绑卡、下线）；先限时、后常态，生图生视频单独成栏（学懒猫的场景分类）。

02

机器对账

学 free-token-radar + flatkey：每个数字必须能在官方原文或官方文档里找到才算核实，并记下核查日期；聚合页收录更新 ≠ 规则变化，不报。

03

核实分级 + 绑卡一票否决

学白嫖计：「目录收录」与「额度已核实」分开标注，商用许可、水印单列成字段。绑卡单独设闸：要绑卡、验证支付方式或先充值 / 先有付费余额才能用的，直接不纳入主列表（本轮已剔除 Cerebras、Pollinations），只在「已排除」留记录说明原因。

04

实测口径

学 awesome-free-ai-coding：官方宣称限速与实测有效限速分开记（如 Agnes 宣称 30 RPM、实测约 10 RPM），评分里的实用性按实测口径扣分。

05

全量到期监控

学 Free Token Hunter + 白嫖计变更监控：固定截止跑倒计时，每日 / 每月型跑重置倒计时，无截止日的常驻档每周复核政策页，降额、加绑卡、退役都算「变化」要报。

06

两层评分：卡片总分 + 逐模型分

卡片右上角给整个羊毛一个总分：易薅程度 45% + 实用性 55%（实用性取最值得用模型的实用分），不含智力与额度，先帮你筛掉难领又不好用的。点开「免费模型明细」再看每个具体模型自己的智力 40% + 额度 30% + 实用性 30%；评分榜也按具体模型排，不按平台排。

和 Magpie 怎么衔接？

Magpie 是消费层：把你已领到的 Key、订阅和免费额度集中托管、协议互转、耗尽自动换号 —— 但它不会告诉你哪家刚发了新额度。这一页是它前面的发现层：在这里发现并核实 → 回官方页手动领取 → 把 Key 交给 Magpie 统一调度。海外档大多是 OpenAI 兼容端点（Cloudflare、Agnes、Groq、OpenRouter 都可直接填 Base URL + Key），和国内档放进同一个 Magpie 池子里轮换正合适。提醒一句：批量发放基本都要登录、实名、手动点领取，任何让你交出厂商账号密码或主 API Key 去“自动薅”的工具都不要用。

数据口径：本页为 2026-11-03 核查的快照。国内活动以厂商官方页当时显示为准；海外免费档为 2026-10 月下旬公开文档与多家聚合库交叉核对的口径，这类免费层变动极快（限额、绑卡要求、模型阵容都可能周级变化），领取与接入前请再看一眼官方页。纳入标准：需绑卡 / 验证支付方式 / 预充值的已剔除（见「争议与已排除」）。卡片内的直达按钮为 2026-11-03 核对过的官方入口；没有公开领取页的客户端类活动只写步骤、不放链接。卡片右上角总分公式：易薅程度（0–5）×20×45% ＋ 实用性（取最值得用模型的实用分 0–5）×20×55%，满分 100，不含智力与额度；点开明细里的逐模型分仍为智力 40% + 额度 30% + 实用性 30% 的编辑评分、不是基准跑分。模型名单以点开时官方目录为准，聚合型平台（如 OpenRouter、NVIDIA Build）的免费阵容会轮换。倒计时按你设备上的当前时间实时计算。
